# 🤖 Rule-Based AI Chatbot

A simple **Rule-Based AI Chatbot** developed as **Project 1** during the **DecodeLabs Artificial Intelligence Internship (2026)**.

This chatbot simulates basic human conversation using predefined rules and conditional logic. It is designed to demonstrate the fundamentals of Artificial Intelligence without using Machine Learning or Deep Learning models. The project focuses on Python programming concepts such as control flow, functions, loops, dictionaries, string manipulation, and modular programming. It aligns with the internship objective of building a chatbot capable of handling greetings, predefined questions, unknown inputs, and exit commands through rule-based decision making. :contentReference[oaicite:0]{index=0}

---

# 🚀 Features

- Interactive command-line chatbot
- Continuous conversation using an infinite loop
- Handles greetings and common user queries
- Keyword-based response matching
- Exit command to terminate the conversation
- Default response for unknown inputs
- Modular Python code structure
- Clean and readable implementation
